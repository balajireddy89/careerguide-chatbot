About CareerGuide AI

CareerGuide AI is a student-focused chatbot designed to help students explore technology careers, understand required skills, and discover practical learning roadmaps.

  • Primary AI Model: Powered by fast LLMs via OpenAI-compatible REST API.
  • Model Fallback System: Automatic fallback to secondary provider if primary is unavailable.
  • Local Knowledge Base: Enriched with career data for 10+ popular software domains.
  • Tech Stack: Java Spring Boot, REST API, HTML5/CSS3, Vanilla JS.
